# Dashboard Proiecte

O aplicație web pentru gestionarea proiectelor personale, cu frontend React și backend Express + MongoDB.

## Tehnologii folosite

- React
- Vite
- React Router DOM
- Express
- MongoDB
- Mongoose

## Instalare și rulare

1. Instalează dependențele frontend:

```bash
npm install
```

2. Pornește serverul backend:

```bash
cd server
node index.js
```

3. Pornește frontend-ul:

```bash
cd ..
npm run dev
```

4. Deschide aplicația în browser la:

```text
http://127.0.0.1:5173/
```
